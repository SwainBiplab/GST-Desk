# Keyboard map

Everything reachable with the mouse is reachable from the keyboard. Press `?` anywhere (outside a text field) to see this map in the app.

## Anywhere

| Keys   | Does                                                               |
| ------ | ------------------------------------------------------------------ |
| Ctrl+K | Open the command bar                                               |
| /      | Open the command bar (when not typing in a field)                  |
| ?      | Show this keyboard map                                             |
| F1     | Open help for the screen you are on                                |
| Esc    | Close the command bar or a dialog; focus returns to where you were |

## In the Inbox

These work on the Inbox page, in both Shop and Books, and are ignored while you are typing in a field.

| Keys  | Does                                                                        |
| ----- | --------------------------------------------------------------------------- |
| J / K | Inbox: move to the next or previous item                                    |
| A     | Inbox: accept the selected item (the next one moves up, so keep pressing A) |
| E     | Inbox: change the selected item, then accept                                |
| R     | Inbox: reject the selected item (asks for an optional reason)               |
| S     | Inbox: snooze the selected item                                             |
| O     | Inbox: open the record the item is about                                    |

## Books only

| Keys     | Does                   |
| -------- | ---------------------- |
| N        | New document menu      |
| G then H | Go to Dashboard        |
| G then D | Go to Documents        |
| G then P | Go to Parties          |
| G then I | Go to Items            |
| G then R | Go to Reports          |
| G then L | Go to Ledger           |
| G then T | Go to Stock            |
| G then M | Go to Money (payments) |
| G then B | Go to Inbox            |
| G then S | Go to Settings         |

Press `G`, then the letter within about a second. Shortcuts are ignored while you are typing in an input.

## Command bar

Open it, then type:

- a page or action name (`parties`, `toggle theme`, `new invoice`);
- a name, GSTIN, SKU or document number to search parties, items and documents;
- a command with arguments: `pay 5000 to Sharma`, `received 1.5 lakh from Iyer`, `new invoice for Das`, `go reports`. Amounts accept `k`, `lakh`, `cr` and `₹`;
- anything else: it is offered to the assistant, which is not available until a model is configured (Phase 2).

Use Up and Down to choose, Enter to run, Esc to close.
