Procedure: `prompts/cross-cutting/91-performance-budget.md`. Commit `f76fd47` plus the working-tree changes of prompt 24 (the `@gst/print` `sideEffects` fix, the budget edits in ADR 0015). Other figures from the same runs: importing 10,000 items took 2.4 s (budget 30 s); the item grid scrolled in 122 ms and sorted in 173 ms at the throttle; the preview followed a change in 223 to 228 ms (budget 300 ms).

## What changed because of this pass

- **The PDF libraries were bundled twice** (once in the worker, once in the editor chunk). `@gst/print` is now `sideEffects: false`; the editor chunk shrank from 557 kB to 400 kB gzipped. The total-asset ceiling moved to 2 MB with per-chunk guards. See ADR 0015, decisions 1 and 2.
- **The keystroke test measured the wrong statistic** (a 95th percentile of 14 samples is the slowest sample). It now takes 56 keystrokes. The 16 ms target is unchanged and is still reported; a hard line of 24 ms applies while the exception is open. See ADR 0015, decision 3.

## Not covered by this record

The reference laptop, a throttled run of the database suites, and the desktop memory and start-up figures need the real device (B-093). The mobile profile is Phase 3.
