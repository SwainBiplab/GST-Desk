# Security review: Phase 2

Scope: the code shipped by prompts 30 to 36 (GST returns, GSTR-2B reconciliation, the GSP adapter for e-invoices
and e-way bills, TDS/TCS and income tax, Tally/Vyapar/Excel migration, LAN access and device pairing, Tier 1
local AI), reviewed against the checklist in `prompts/cross-cutting/90-security-review.md` on 2026-11-07. The
threat model was refreshed first (`docs/security/threat-model.md`: GSP credentials, paired-device tokens and
model files as assets; the GSP connection, import files, the LAN server, the model manifest and scanned bills
as entry points).

## Result

No open Must findings. Three Must findings were found and fixed in this review; the Should findings are in the
backlog with owners. Semgrep and gitleaks still could not be run here (B-089); a regex scan of the whole history
found nothing, and `cargo audit` now runs in CI.

## Checklist

| Item                                                                    | Result | Evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Input validation at every boundary                                      | Pass   | LAN: every `/rpc` body is decoded by the wire codec, the method table is a whitelist, `parties.create` takes a field whitelist, bodies are capped in Rust and the forward times out. GSP: typed request and response records, the portal's errors mapped to a fixed list. Imports: streaming XML with strict numbers and a dry run; size caps (finding 4). AI: manifest by Zod and signature; scans by magic bytes and 10 MB; model answers by grammar then schema; watched-folder reads by name only (finding 3). |
| SQL only through Drizzle or parameterised queries                       | Pass   | Every `sql.raw` was read again: constants and fixed column names only (`stats.ts`, `reports.ts`, `dialect.ts`, migrations). The Phase 2 repositories (`gstr`, `gstr2b`, `einvoice`, `direct-tax`, `interop`, `inventory`, `lan-devices`, the AI adapters) use `sql\`\``templates with`${}`parameters and`sql.join` of parameters; no string-built SQL.                                                                                                                                                             |
| RLS on every Postgres table; cross-tenant tests; `SET LOCAL app.org_id` | Pass   | A script over the generated migrations: all 41 tenant tables have the `tenant_isolation` policy and all 46 tables the delete guard (the Phase 2 tables through `9003` to `9007`); cross-tenant tests for the new tables run against PGlite (`interop`, `lan-devices`, `direct-tax`, `gstr2b`, `einvoice`, AI vectors); `runInTx` sets the organisation on every transaction.                                                                                                                                       |

## Residual risk

- The desktop glue for the LAN server and offline AI is reviewed, not run (finding 10).
- A tablet user who approves the certificate warning without checking the fingerprint could pair with an impostor on the same network; the one-time code shown only on the real desktop limits what that gains.
- Data at rest is still not encrypted (B-087).
